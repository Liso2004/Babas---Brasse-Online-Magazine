# Asset And Editorial Approval Register

Every production asset needs a known source, rights basis, credit, alt text where meaningful, and editorial approval.

## Assets Requiring Explicit Launch Approval

- `apps/web/public/media/artwork-feature-placeholder.jpg`
- `apps/web/public/media/opening-banner-placeholder.jpg`
- `apps/web/public/media/photography-feature-placeholder.jpg`
- `apps/web/public/media/profile-placeholder.jpg`
- All files under `apps/web/public/media/editorial`
- All files under `apps/web/public/media/team`
- All files under `apps/web/public/media/carousel`
- All files under `apps/web/public/media/moodboard`
- `apps/api/data/editorial-seed.json`

For each asset or collection, record in the private rights register:

| Field | Required |
| --- | --- |
| File or content identifier | Yes |
| Creator/source | Yes |
| License, assignment, permission, or ownership basis | Yes |
| Usage restrictions and expiry | When applicable |
| Required credit | When applicable |
| Final alt text/caption | For published visual media |
| Editorial approval | Yes |

Placeholder-named files must either be replaced with final approved work or explicitly approved as intentional launch assets.
